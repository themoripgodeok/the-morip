# 더몰입 로컬 좌석 관리 프로그램

ClassUp에 로그인된 이 컴퓨터에서 학생/출결 정보를 자동으로 가져와 하드디스크에 저장하고, 기존 75석 좌석표를 로컬 브라우저에서 실행합니다. 외부 데이터 서버나 클라우드 저장소는 사용하지 않습니다.

## 처음 설치하기

1. GitHub 저장소에서 **Code → Download ZIP**으로 전체 파일을 내려받고 압축을 풉니다.
2. Windows에 Python 3를 설치합니다. 설치 화면에서 **Add Python to PATH**를 선택합니다.
3. 기존 좌석 배치를 보존하려면 먼저 기존 웹 좌석표를 엽니다: https://themoripgodeok.github.io/the-morip/seat-map.html
4. 기존 좌석표에서 **파일로 저장**을 눌러 좌석 배치 JSON을 컴퓨터에 저장합니다.
5. 압축을 푼 폴더의 `local-app/run_local.bat`를 더블클릭합니다.
6. 로컬 좌석표가 열리면 **파일 가져오기**를 눌러 4번에서 저장한 좌석 배치 JSON을 가져옵니다. 이후 **저장**을 누릅니다.

## ClassUp 자동 수집 연결

1. Whale 주소창에 `whale://extensions`를 입력합니다. Chrome은 `chrome://extensions`입니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**를 누릅니다.
4. 압축을 푼 폴더 안의 `local-app/extension` 폴더를 선택합니다.
5. ClassUp에 로그인한 뒤 학생 관리 페이지를 새로고침합니다.
6. 로컬 좌석표 페이지를 열어 두면 자동 수집 데이터가 약 30초마다 출결에 반영됩니다. 학생 명단은 5분마다 다시 확인합니다.

## 실행 방법

- 실행 파일: `local-app/run_local.bat`
- 좌석표 주소: http://127.0.0.1:8765/seat-map.html
- 로컬 서버를 실행한 검은 창을 닫으면 연결이 중단됩니다. 계속 사용하려면 그 창을 열어 두세요.

## 내 컴퓨터에 저장되는 파일

- `local-app/data/classup.json`: 학생 ID/이름/좌석번호 및 출결에 필요한 항목
- `local-app/data/layout.json`: 75석 좌석 배치와 좌석별 연결 정보

이 데이터는 이 컴퓨터의 디스크에만 저장됩니다. `local-app/data` 폴더를 외장 드라이브 등에 정기적으로 백업하세요. 이 폴더는 GitHub에 업로드되지 않도록 설정되어 있습니다.

## 개인정보 및 보안

- 수집기는 ClassUp 로그인 브라우저의 세션을 사용합니다.
- Authorization 헤더, 비밀번호, 쿠키는 읽거나 파일에 저장하지 않습니다.
- 학생 정보는 좌석 연결에 필요한 학생 ID, 이름, 좌석번호만 수집합니다.
- 로컬 서버는 `127.0.0.1`에서만 열리므로 같은 네트워크의 다른 기기에서 직접 접속할 수 없습니다.
- 자동 수집 컴퓨터가 꺼져 있거나 ClassUp 로그아웃 상태면 수집이 중단됩니다.

## 현재 버전의 범위

로컬 저장 서버, ClassUp 브라우저 수집 확장, 기존 좌석표의 로컬 데이터 읽기/저장 연결을 구성했습니다. 실제 ClassUp 계정에서 첫 연결 테스트는 사용자의 Whale 환경에서 진행해야 합니다. ClassUp API 응답 형식이나 접근 정책이 바뀌면 수집기 수정이 필요할 수 있습니다.
